# Sophos XGS on AWS

Sophos Firewall **Home** is an on-prem / home-lab license and is not valid
for AWS Marketplace PAYG images.

Use VirtualBox, VMware, Ludus or Proxmox with the official Home ISO instead.
If you need a cloud firewall, use a Sophos PAYG AMI under your own Sophos
contract — that is outside the scope of this extension.
