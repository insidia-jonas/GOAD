# Extensions

- [guacamole](guacamole.md) : Add a vm with guacamole to get a quick access on lab
- [exchange](exchange.md) : Add an exchange to GOAD or GOAD-Light lab
- [ws01](ws01.md) : Add an hardened workstation to GOAD or GOAD-Light lab
- [lx01](lx01.md) : Add a linux vm to GOAD or GOAD-Light lab
- [wazuh](wazuh.md) : Add wazuh SIEM/EDR to visualize alerts (4.14 + SOCFortress/Sigma/custom rules)
- [edr](edr.md) : Select Wazuh, Defender, Sophos, Elastic Defend or Bitdefender per machine
- [elastic_edr](elastic_edr.md) : Elastic Security 8.x (30-day trial) + Fleet + Elastic Defend on `.54`
- [sophos_xgs](sophos_xgs.md) : Sophos Firewall XGS (Home license) with API/XML lab template
- [elk](elk.md) : Add an ELK to collect and read the logs
